orange 的个人主页 · 2026 秋招工程档案。

- 字体：Space Grotesk / IBM Plex Mono（OFL 许可，见 `assets/fonts/LICENSE.txt`）
- 项目配图为「工程制图」风格 SVG 插画，非项目实物照片

本机源文件与验证工具不在本仓库中维护。
